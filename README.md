# NGO CMS

A simple NGO Content Management System (CMS) built using Django for the backend and HTML, CSS, and JavaScript for the frontend.

## Features
- Home Page
- About Page
- Projects
- Blog
- Contact
- Donation Page
- Media Gallery

## Technologies Used
- Python
- Django
- HTML5
- CSS3
- JavaScript

## Project Structure

```
NGO-CMS/
├── backend/
└── frontend/
```
